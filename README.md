#  Typing Fingerprint
### Keystroke Dynamics Based User Verification

##  About the Project
Typing Fingerprint is a web-based project that identifies users by analyzing their unique typing patterns.

It measures how long a user holds a key and the time gap between consecutive key presses. These patterns are used to compare a user's current typing behavior with their previously enrolled profile.

##  Objectives
- Analyze individual typing patterns.
- Measure dwell time and flight time.
- Enroll users and save their typing profiles.
- Verify users by comparing typing rhythms.
- Display typing speed and accuracy.

## Features
- **User Enrollment:** Register users by collecting their typing patterns.
- **User Verification:** Compare current typing patterns with saved profiles.
- **Confidence Meter:** Display the typing similarity score.
- **Statistics Dashboard:** View stored user profiles and typing statistics.
- **Typing Speed Test:** Calculate WPM, accuracy, and typing time.
- **Paste Detection:** Detect paste actions during typing.

##  Technologies Used
- HTML
- CSS
- JavaScript
- Browser LocalStorage

##  How It Works
1. The user enters their username.
2. The system collects typing samples.
3. Dwell time and flight time are calculated.
4. The user's typing profile is saved in LocalStorage.
5. During verification, the system compares the new typing pattern with the saved profile.
6. The similarity score is displayed.
